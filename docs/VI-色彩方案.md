## 一、核心三色

| 角色 | HEX | RGB | RGBA | 使用场景 |
|---|---|---|---|---|
| 主色① 梅子紫 Plum | `#983269` | `rgb(152, 50, 105)` | `rgba(152, 50, 105, 1)` | 品牌识别：主按钮/CTA 填充、选中态、页头强调、进度条、焦点环 |
| 主色② 纸白 Paper | `#F6F6F4` | `rgb(246, 246, 244)` | `rgba(246, 246, 244, 1)` | 页面画布底色、卡片底色、深色舞台上的正文白 |
| 辅助色 金琥珀 Amber Gold | `#B8891F` | `rgb(184, 137, 31)` | `rgba(184, 137, 31, 1)` | 强调文字/图标、卡片描边与悬停描边、徽标、数据高亮、渐变光的暖端 |

辅助色的适配逻辑：与梅子紫同属低明度宝石色调，色相从 320° 转到 40°，形成近互补的暖冷对照；
- 色相：清晰对比（紫红 ↔ 金黄）
- 明度：接近（都在 L* 45–50 区间），因此并排时不抢主色
- 饱和度：略低（金琥珀比梅子紫更"哑"），避免两个高饱和色互相打架
- 蓝紫底 + 暖金强调，与影视行业「片头字幕 / 胶片暖光」的视觉语汇一致，不引入第三个色系

## 三、视觉风格描述

**优雅 · 现代 · 柔和**——"电影片头 + 高级杂志"的质感。

- 优雅：纸白大留白 + 细发丝线（1px `--color-border`）构图，不用重投影与边框；
- 现代：唯一强调色只出现在"动作与数据"上（按钮、选中态、进度、关键数字），不做彩虹式配色；
- 柔和：所有"高光/发光"改为低透明度的色彩晕染（`--glow-*` 用 30%–55% 不透明度），去掉原暗色科技风的霓虹描边；
- 节奏：明暗分区——hero/页头/浮层/页脚保留深梅子"舞台"，内容主体用纸白"纸面"

## 四、使用场景分配

| 场景 | 用色 | 实例 |
|---|---|---|
| 主按钮 / CTA | 梅子紫填充 + 纸白文字 | 顶栏「规划我的未来」、测评「下一步」 |
| 次按钮 / 幽灵按钮 | 透明底 + 细描边，悬停转梅子紫文字 | 「重测」「返回」 |
| 选中态 / 筛选激活 | 梅子紫填充（浅底）或浅粉 `#E9A6CB` 文字+晕染（深底） | 案例分类、国家筛选、时间轴视图切换 |
| 链接 / 行内强调 | 浅底 `#7C2755`；深底 `#E9A6CB` | 正文可点文字、区块小标题 |
| 悬停状态 | 描边转金琥珀 `#B8891F` + 文字转为正文墨色，或底色升一级（`--color-surface-2`） | 卡片、筛选按钮、导师卡片 |
| 强调文字 / 小标题 | 金琥珀 `#B8891F`（浅底）/ `#E7C36B`（深底） | 区块 eyebrow、课程产品页小标题 |
| 卡片边框 / 分隔线 | 浅底 `#DED7D2` 发丝线；悬停用金琥珀 30% 透明描边 | 案例卡、导师卡、offer 网格 |
| 关键数字 / 数据 | 金琥珀（浅底 `#B8891F`，深底 `#E7C36B`） | hero 统计 8 / 61 / 146 / 341 |
| 焦点环 | 梅子紫 2px 外描边 | 所有可聚焦元素（Tab 键） |
| 深色舞台 | 底 `#20101A`，文字纸白，强调转浅粉/暖金 | hero、页头、导航浮层、侧栏、课程/图片浮层、页脚 |

## 六、落地方式

- 全部颜色以 CSS 变量集中在 `assets/css/style.css` 的 `:root`，全站组件只引用变量，无硬编码色值残留。
- 深色舞台通过一条作用域规则就地覆盖同名变量，覆盖 hero、页头、导航浮层、侧栏、课程/图片浮层、页脚：

```css
/* assets/css/style.css —— 深色「舞台」作用域（就地覆盖令牌） */
.hero, .plan-hero, .timeline-hero, .navbar, .nav-menu-overlay, .sidebar,
.course-overlay, .minicourse-modal, .img-modal-backdrop, footer { … }
```

- 校验工具（`tools/verify/`）：`contrast.mjs` 全站文本对比度、`states.mjs` 悬停/激活态与浮层、`shots.mjs` 截图留档、`cdp2.mjs` 28 项交互回归。
- 维护建议：新增组件只使用变量；浅底用 `--color-primary-bright` / `--color-accent-deep`，深底用 `--color-primary-bright`（自动切浅粉）/ `--color-accent-bright`。
- 禁止：再次引入霓虹发光；在梅子紫填充上使用深色墨字（`#26181F` 等）——必须用纸白。
